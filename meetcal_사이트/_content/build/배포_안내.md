## 1. 올릴 것은 3개뿐

| 무엇 | 이 폴더에서 | 저장소 어디로 |
|---|---|---|
| `ohaeng/` 폴더 통째로 | `content/deploy/ohaeng/` | 루트 아래 새 폴더 |
| `sitemap.xml` | `content/deploy/sitemap.xml` | 루트 (덮어쓰기) |
| `index.html` | `Wep-meetcal.co.kr/index.html` | 루트 (덮어쓰기) |

**올리지 않아도 되는 것** — 이미 저장소에 있습니다.

- `og-image.png` — 7월에 올리셨습니다. 빠져 있던 건 파일이 아니라 HTML의 `og:image` 태그였고, 이번 패치에 들어갔습니다
- `robots.txt` — 이미 있고 내용도 동일합니다
- `meetcal-core.js` — 궁합 글 쓸 때 올리면 됩니다
- `CNAME` — 건드리지 마세요

기존 파일은 위 2개(`index.html`, `sitemap.xml`) 외에 하나도 건드리지 않습니다.

## 2. 올리는 순서 (GitHub 웹)

1. `https://github.com/gbbj-10/meet-cal` 접속
2. 초록색 **`Add file`** → **`Upload files`**
3. **`ohaeng` 폴더를 통째로 드래그** — ⚠️ "choose your files" 버튼으로는 폴더를 못 고릅니다. 드래그해야 구조가 유지됩니다
4. 커밋 메시지 `오행 이야기 글 3편 추가` → **`Commit changes`**
5. 다시 **`Add file` → `Upload files`** → `index.html`, `sitemap.xml` 드래그 (같은 이름은 자동 덮어쓰기, 기존 버전은 히스토리에 남음)
6. 커밋 메시지 `GA4·애드센스·카카오 공유 추가, canonical non-www 정정`
7. **`Actions`** 탭에서 초록 체크 = 배포 완료 (1~3분)

확인:

```
https://meetcal.co.kr/ohaeng/                      ← 글 목록
https://meetcal.co.kr/ohaeng/wolbyeol-ohaeng.html  ← 글 1
https://meetcal.co.kr/ohaeng/buljokhan-ohaeng.html ← 글 2 (오행 계산기)
https://meetcal.co.kr/ohaeng/taeeonan-sigak.html   ← 글 3 (오행 계산기)
https://meetcal.co.kr/ohaeng/game.html             ← 준비 중 (noindex)
https://meetcal.co.kr/                             ← 결과 화면에 공유 버튼·광고·오행 링크
```

안 바뀌면 `Ctrl`+`Shift`+`R` 로 캐시를 비우세요.
